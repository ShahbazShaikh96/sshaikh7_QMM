# Quantitative Management Modelling Projects

This repository contains quantitative management modeling assignments focused on linear programming and optimization.

| Folder | Project Name | Main Work |
| --- | --- | --- |
| `01_Product_Mix_Profit_Maximization_LP` | Product Mix Profit Maximization with Linear Programming | Determines optimal product production across plants to maximize profit subject to capacity, storage, and demand constraints |
| `02_Production_Shipping_Cost_Minimization_LP` | Production and Shipping Cost Minimization with Linear Programming | Finds the lowest-cost shipping plan from plants to wholesalers while satisfying capacity and demand constraints |
