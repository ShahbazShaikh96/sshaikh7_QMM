# Production and Shipping Cost Minimization with Linear Programming

Uses linear programming in R to create the lowest-cost shipping plan from production plants to wholesalers.

## Main Work

- defines six plant-to-wholesaler shipping decision variables
- minimizes combined production and shipping cost
- applies plant supply constraints
- applies wholesaler demand constraints
- solves the model with `lpSolve`
- reports the optimal shipping plan and cost interpretation

- `Production_Shipping_Cost_Minimization_LP.Rmd`: source analysis
