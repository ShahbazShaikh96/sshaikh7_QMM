# Product Mix Profit Maximization with Linear Programming

Uses linear programming in R to determine the optimal product mix across multiple plants.

## Main Work

- defines production decision variables
- maximizes total profit
- applies capacity, storage, and demand constraints
- solves the model with `lpSolve`
- interprets binding constraints and production priorities

## Files

- `Product_Mix_Profit_Maximization_LP.Rmd`: source analysis
- `Product_Mix_Profit_Maximization_LP.html`: rendered report
- `Product_Mix_Profit_Maximization_LP_Output`: original output artifact
